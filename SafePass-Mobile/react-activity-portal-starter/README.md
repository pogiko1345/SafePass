# React Activity Portal Starter

This is an unfinished starter for the React JS Practical Assessment.

It includes:

- One React project
- One shared Navbar
- Home page
- Activity 1: Login Authentication
- Activity 2: Student Grade Evaluation
- Activity 3: Password Strength Checker
- Activity 4: Electricity Bill Calculator

The important activity logic is intentionally left as `TODO` comments so you can complete it yourself.

## Run It

```bash
npm install
npm run dev
```
